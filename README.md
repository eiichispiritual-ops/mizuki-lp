# みづき セールスレター LP

本鑑定・伴走サポートのセールスレター2枚。

- `kantei/` LP① 本鑑定のご案内（無料鑑定 → 4,980円 / 9,980円）
- `bansou/` LP② 月読の伴走（本鑑定 → 15,800円 / 39,800円 / 99,800円 / 159,800円）
- `img/` 画像素材

## 写真の差し替え

`img/mizuki.jpg` を置くと、両LPの追伸セクションに自動反映されます。
未配置の場合は月の写真にフォールバックします。

推奨: 縦4:5 / 幅1600px以下
